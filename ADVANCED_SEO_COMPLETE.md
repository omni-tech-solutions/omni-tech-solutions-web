## 🚀 How to Use Everything

### **1. Update Site Information**

Edit `app/utils/seo.ts`:
```typescript
export const siteConfig = {
  name: 'OMNI Tech Solutions',
  url: 'https://tech.omni-solutions.co',
  // Update descriptions, keywords, contact info
}
```

### **2. Enable Google Analytics**

In `app/layout.tsx`, add:
```tsx
import { GoogleAnalytics } from '@/app/components/analytics/GoogleAnalytics';

// In the component:
<GoogleAnalytics measurementId="G-XXXXXXXXXX" />
```

### **3. Enable Service Worker**

In `app/layout.tsx`, add:
```tsx
useEffect(() => {
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js');
  }
}, []);
```

### **4. Add Social Media Links**

In `app/utils/seo.ts`, organization schema:
```typescript
sameAs: [
  'https://facebook.com/yourpage',
  'https://twitter.com/yourhandle',
  'https://linkedin.com/company/yourcompany',
  'https://instagram.com/yourprofile'
]
```

### **5. Add Location Details**

In `app/utils/advanced-seo.ts`, use:
```typescript
generateEnhancedLocalBusinessSchema({
  address: 'Your Street Address',
  city: 'Your City',
  postalCode: '1234',
  latitude: 42.6977,
  longitude: 23.3219,
  serviceAreas: ['Sofia', 'Plovdiv', 'Varna', 'Burgas']
})
```

### **6. Track Events**

Use tracking functions anywhere:
```typescript
import { trackEvent, trackConversion } from '@/app/components/analytics/AnalyticsProvider';

// Track button clicks
trackEvent('button_click', { button_name: 'Contact Us' });

// Track conversions
trackConversion('form_submission', 100);
```
